# Running JobTransit

This project keeps its original React, TypeScript, and Vite structure.

- Install the locked dependencies with `npm ci`.
- Click **Run** to start the **Start application** workflow, or run `npm run dev -- --host 0.0.0.0 --port 5000`.
- Open Preview to view the site.
- Build for production with `npm run build`; the output is in `dist`.

The landing page does not require secrets. Application configuration examples are in `.env.example`.
